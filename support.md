# Support — LLM Context & Usage Meter

**Support contact:** valaritas.software@protonmail.com

When contacting support, include the Extension version, browser version, provider name, and a description of the problem. Do not send conversation text, passwords, cookies, payment-card details, or other sensitive content.

Common first steps:

1. Reload the extension from the current release package.
2. Refresh the provider chat page.
3. Confirm that local tracking consent was granted.
4. Check the model confidence and whether the provider is marked Experimental.
5. For payment issues, use ExtensionPay's subscription page and include only the relevant payment reference.
